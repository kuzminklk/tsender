## About

### Description

Web-interface for interaction with TSender smart contract for sending a lot of tokens, like for airdrop.

### Purpose

Part of Full-stack Web 3 course from Cyfrin Updraft and as submodule in [appropriate repository](https://github.com/kuzminklk/cyfrin-updraft)

### Technologies

Development: Visual Studio Code, Artificial intelligence assistance  
Programming language: JavaScript → TypeScript  
Environment: Node.js → pnpm  
Framework: React, React-Query → Next.js (app router, “/src” directory) → Viem, Wagmi, Rainbow Kit  
Formatting: “.editorconfig”, “.vscode/…”, Prettier  
Testing: Vitest  
Linting: ESLint, TypeScript checks
